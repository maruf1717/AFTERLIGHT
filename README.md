# AFTERLIGHT

Виртуальный город, который меняют его жители. Проект развивается по миссиям.

## Статус

| Миссия | Что сделано |
| ------ | ----------- |
| **01 — Город** ✅ | 3D-город с тремя районами (Downtown, Residential, Industrial), переключение районов, карточки зданий, справочник с поиском и фильтрами, день/ночь, адаптация под телефон |
| 02 — … | регистрация, профиль, свой дом (план) |

## Запуск

```bash
cd frontend
npm install
npm run dev        # http://localhost:5173
npm run build      # продакшн-сборка в frontend/dist
```

## Структура

```
frontend/src/
  data/      модель города: типы, генерация зданий, районы (в будущем приходит из API)
  store/     состояние приложения (zustand): выбранный район/здание, день/ночь, качество
  scene/     3D-сцена (three.js + react-three-fiber): здания, районы, трафик, камера
  ui/        интерфейс поверх сцены: панели, справочник, переключатель районов
```

Город описан данными (`data/city.ts`): район — это сетка участков, здания создаются детерминированным
генератором, а достопримечательности задаются вручную. Те же структуры (`District`, `Building`) потом
будет отдавать backend на FastAPI, и интерфейс менять не придётся.

## Управление

- ПК: ЛКМ — вращение, ПКМ — сдвиг, колесо — зум, `1/2/3` — районы, `←/→` — здания, `N` — день/ночь, `Esc` — закрыть
- Телефон: тап по зданию, два пальца — поворот и зум, кнопка списка — справочник зданий
