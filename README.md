# AFTERLIGHT

Живой город на острове, который поднимают его жители. Браузерная игра на React и three.js.

## Что уже работает (v0.3)

- **Город живёт сам.** Каждый игровой день (по умолчанию 15 реальных минут) симуляция пересчитывает 9 потребностей: электричество, воду, жильё, работу, еду, здоровье, образование, безопасность и отдых. Если чего-то не хватает, начинается кризис и жители уезжают.
- **Старт с посёлка.** 120 жителей, изношенная ТЭЦ и ни одного врача. Дома, офисы и магазины город строит сам, когда растёт.
- **Задания.** Ежедневные (мини-игра с проводкой, доставка посылки, опрос, обход района, оценка заведений) и творческие (текст или рисунок), которые проверяет основатель.
- **Городские проекты.** Поликлиника, ремонт ТЭЦ, больница, парк, солнечная станция и другие строятся только на взносы жителей. Пока идёт сбор, на участке стоит стройка с краном.
- **Бизнес жителей.** Кофейня, закусочная, ресторан, магазин или автосервис со своим названием, цветом, ценами и улучшениями (терраса, парковка, окно выдачи, озеленение). Доход зависит от района, цен, конкурентов и состояния города.
- **Рейтинг.** Строители, творцы и бизнесы.
- **Админ-панель основателя.** Начисление Искр, проверка работ, настройка баланса, творческие задания, перезапуск города.
- **Графика.** Остров с рекой, мостами, пляжами и лесом. Машины с крутящимися колёсами и фарами, пешеходы, светофоры, зебры. Отражения, мягкие тени, свечение фонарей ночью. На телефонах по умолчанию включён экономный режим.

## Где хранится игра

В опубликованной версии общие данные лежат в базе данных страницы: все, у кого есть доступ к странице, играют в одном городе. Основатель (владелец страницы) видит админку. При локальном запуске (`npm run dev`) город хранится в браузере.

## Запуск

```bash
cd frontend
npm install
npm run dev        # http://localhost:5173
npm run build      # сборка в frontend/dist
```

## Структура

```
frontend/src/
  data/      статичная карта: районы, участки, генератор зданий
  game/      игра: каталог (баланс, проекты, задания), симуляция, хранилище, связь с базой
  scene/     3D: остров, река, лес, здания, машины, пешеходы, эффекты
  ui/        интерфейс: панели, вкладки, мини-игры, админка
  store/     состояние камеры и выбора на карте
```

Симуляция (`game/sim.ts`) — чистая функция от настроек, записей жителей и времени. Каждый клиент считает один и тот же город без отдельного сервера. Когда появится backend на FastAPI, он будет считать то же самое на сервере.

## Управление

- Компьютер: левая кнопка мыши крутит, правая двигает, колёсико приближает. `1/2/3` — районы, `←/→` — здания, `N` — ночь, `Esc` — закрыть.
- Телефон: одним пальцем крутить, двумя приближать, нажать на здание — карточка.
